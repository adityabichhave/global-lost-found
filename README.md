# 🌍 Global Lost & Found

A modern, real-time **Lost & Found web platform** built using **Firebase + Tailwind CSS**, enabling users to report lost or found items, chat securely, and reconnect with what matters.

## ✨ Features

- 🔍 Report **Lost Items**
- 📦 Report **Found Items**
- 💬 Real-time **Chat** using Firestore
- 📱 WhatsApp click-to-contact
- 🖼️ Image upload with Base64 preview
- 🔄 Live updates (Firestore)
- 🎨 Premium UI with Tailwind CSS
- 🔐 Anonymous authentication
- 🚀 Deployed on Firebase Hosting

## 🛠 Tech Stack

- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Backend:** Firebase Firestore
- **Auth:** Firebase Anonymous Auth
- **Hosting:** Firebase Hosting
